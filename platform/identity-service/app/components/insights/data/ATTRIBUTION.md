# Place data attribution

`places.tsv` is derived from **GeoNames** (https://www.geonames.org), used under
the **Creative Commons Attribution 4.0 International** licence. It is a subset of
Mangaly's bundled list (India population >= 5,000; elsewhere >= 100,000), rebuilt
with `scripts/build_insight_places.py`. The Members dashboard credits
"Places: GeoNames (CC BY 4.0)" beneath its maps.
