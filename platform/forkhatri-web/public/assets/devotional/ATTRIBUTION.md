## Decision (2026-09-14): not shown in the app

The hub uses ForKhatri's own original emblem instead, `sahasrarjun-emblem.svg`,
which carries no third-party rights. It is symbolic: a temple arch, a halo of a
thousand arms drawn as rays, his mukut (crown), and a lotus pedestal, with no face.
This photo is kept only as a reference; it is not rendered anywhere. A full
devotional painting can be added later if the community provides one with
written permission.

## Original assessment of this photo

The image has the look of widely circulated devotional calendar art, while Commons
lists it as the uploader's own work. Before public launch, confirm the rights, or
replace it with an image the Khatri community provides or commissions with written
permission. The other Commons portrait (`File:Kartavirya_Arjuna.jpg`) was not used:
it is an edited version of this same artwork set against a battlefield with fire and
lightning, which is not suitable for a calm devotional presence.
