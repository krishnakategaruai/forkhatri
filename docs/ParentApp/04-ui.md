## Visual direction

Dark-first luminous palette with an adaptive light mode; layered translucent
surfaces with soft depth; an ambient animated background; spring-based motion and
View Transitions between sign-in steps and into sheets; variable typography that
works for English, Hindi and Telugu. The earlier navy/saffron static-shell
direction belongs to the superseded prototype in `web/parent-app/`. Each module
portal takes its accent colour from `registry.module.accent`.

## Page structure

Signed out:

1. ForKhatri wordmark and language choice.
2. One conversational card asking one question at a time: phone or email → 6-digit code (with resend countdown) → name and language for a new member.
3. Secondary link "Use a password instead".
4. When `return_to` points at a module, a line naming it ("Sign in to continue to Milavn").

Signed in:

1. Header: wordmark on the left; notifications bell immediately left of the member avatar; avatar always right-most. No tab bar.
2. Intent bar that shows how it understood the request before opening a module.
3. Module portals, ordered by recent entry, then registry order; availability label on each.
4. Floating command orb for navigation and actions.
5. Account sheet (from the avatar): display name, language, masked phone/email, sign-out, and a quiet note that module profiles are managed inside each module.

## Component rules

- Module portals are reusable and data-driven from `GET /v1/modules`.
- Available, in-development and planned states use different labels and actions; availability is never conveyed by colour alone.
- Buttons have visible focus and clear accessible names.
- Icons supplement labels and never replace essential text.
- The shell remains ForKhatri-branded; module accents never replace the brand.
- No portal says or implies "create a new account".
- Code inputs use `inputmode="numeric"` and `autocomplete="one-time-code"`.
- Errors are shown from stable error codes in the member's language.

## Responsive and motion rules

- Mobile-first; usable at 320 CSS pixels without horizontal scrolling.
- Large tap targets for the code input, orb and portals.
- `prefers-reduced-motion` removes non-essential motion and View Transitions.
- Offline or identity-service-unavailable states use the same visual language, with cached portals shown dimmed.

## Themes
Three choices: System (default), Light, Dark (`data-theme` on html, `localStorage` key `fk.theme`, set before first paint by `lib/theme-script.ts`; the `theme-color` meta follows). Signed-out and offline screens use an "arrival look" (aurora background: dark rgb(5,7,15), light rgb(245,241,232)); hub and admin use the "hub look".

## Shape and motion
`--radius` 16px, `--radius-sm` 12px, `--header-h` 60px (68px on wide screens), `--ease` cubic-bezier(.2,.8,.2,1). Framer-motion `AnimatePresence` between sign-in steps; View Transitions (`lib/view-transition.ts`) for sheets; reduced motion removes non-essential motion. Phone hub: tap targets at least 48px and no scrolling at 360x740 (checked by e2e).

## Typography
`--font-ui`: Geist, then Noto Sans Devanagari, Telugu, Kannada, system. `--font-display`: Sora with the same fallbacks (Marathi uses Devanagari). Hindi, Telugu, Marathi and Kannada text must be accurate and respectful (owner rule 2026-09-30).

## Components
Hub: module row/portal button, coming tile (non-interactive), intent chip (`.u-chip`), deity emblem (role=img, masked `sahasrarjun-emblem.svg`, no filter or animation), entering veil, skeleton. Shared (`ui.tsx`, `Sheet.tsx`): modal Sheet with focus trap, segmented radiogroup, toast, icons. Admin kit (`admin/kit.tsx`): PageHead, Section, Kpi, Badge (tones danger, accent, ok, warn), Empty, Field, filter tabs, bottom tab bar with More sheet. Insights: growth chart, MemberMap.

## Responsive
Phone (390): single column; admin bottom tab bar. Wide (1280): admin 248px sidebar; hub column centred. e2e checks cover 360x740 and other sizes in light and dark, en, hi, te.

## Accessibility
Skip link; one h1 per screen; live regions for step changes and errors; named icon buttons; status never by colour alone; e2e checks AA contrast for accent text and muted text (4.5:1) and gold and focus ring (3:1); the coming list is a labelled list for screen readers.

## Known gaps
Not seen in the browser this pass: admin sidebar at 1280px and Insights map visuals.


## Account deletion (added 2026-11-22)

`DeleteAccount.tsx` uses the existing sheet styling; the destructive button is red and labelled in words. English strings were added to all five locale dictionaries; the translations in the other four languages were not reviewed by a native speaker (unverified). Not browser-checked.
