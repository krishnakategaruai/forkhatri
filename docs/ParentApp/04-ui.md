# Parent Application UI

## Visual direction

The parent shell uses the established ForKhatri direction: deep navy foundation, warm off-white surfaces, saffron/amber action accents, restrained green for positive trust states, rounded cards, and multilingual-friendly typography.

## Page structure

1. Header: ForKhatri wordmark, search/context affordance, notification button, member menu.
2. Sidebar or mobile navigation: Home, Modules, Activity, Account.
3. Main hero: welcome message and primary action.
4. Module grid: one card per module with status and entry action.
5. Activity panel: recent member activity and notification preview.
6. Footer/help: trust, privacy, support, and future platform links.

## Component rules

- Module cards are reusable and data-driven.
- Available and planned module states use different labels and actions.
- Buttons have visible focus and clear accessible names.
- Icons supplement labels and never replace essential text.
- The shell remains ForKhatri-branded even when a module-specific context is selected.
- No module card says or implies “create a new account.”

## Responsive rules

- Desktop: two-column application shell with a persistent navigation rail.
- Tablet: compact rail or top navigation with a two-column module grid.
- Mobile: single-column content and bottom navigation.
- Cards and actions must remain usable at 320 CSS pixels without horizontal scrolling.
