Milavn first run — proposal

Five screens from the proposal in modules/MOD02-milavn/ONBOARDING-REDESIGN-2026-10.md. Each note says where the idea comes from. Sample copy is English except screen A2, which shows the Telugu path. Nothing here is built.

Replaces 3 screens. The search box is typed into on the screen itself, no extra sheet. Big city chips cover "I only know my city" and need no typing. Picking a place goes straight in, with no Continue button.

D · Profile: one next question, not a form
