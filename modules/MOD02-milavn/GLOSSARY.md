# Glossary - MOD02 Milavn

Plain-word terms as used in the product and the documents. Use one word per idea (owner rule on terminology).

| Term | Meaning |
|---|---|
| Milavn | ForKhatri's module for real-world meeting: events, circles, chat |
| Activity / Occurrence | an activity is the idea (Sunday badminton); an occurrence is one dated instance. Screens say "event" |
| Event format | the kind of event (workshop, webinar, tournament, satsang, darshan stream and so on), separate from category |
| Category | one of play, meet, eat, learn, work, explore, celebrate, help, professional |
| Around You | Home grouping of nearby events: Today, Tomorrow, This weekend, Coming up |
| Ask Milavn / Ask bar | plain-language search that turns words into filters shown as chips |
| Smart fill | one sentence on Create fills the form |
| Why this | short honest reason an event is shown |
| Interested / Going / Waitlisted | RSVP states; only Going (or checked in, attended) is a confirmed spot |
| Confirmed spot | going, checked in, attended; a paid ticket makes the spot going |
| Hold | a seat reserved while someone pays, released after a time limit |
| Waitlist offer | a freed paid seat offered to the next waitlisted person for a limited time |
| Ticket type | a tier (Standard, Early bird, VIP) with its own price and quota |
| Discount code | percent or fixed reduction with limit and expiry |
| Quota | seats available in one ticket type |
| Capacity | seats for the whole event |
| QR ticket | private code for entry; organizer scans or types the ticket code |
| Check-in | marking a person present (QR, manual, ticket, or Join on an online event) |
| Sandbox | development checkout with no real money |
| Venue | exact address, arrival notes and map pin shown only after a confirmed spot |
| Area / locality | the approximate place shown publicly (city, zone, locality) |
| Location precision | member setting: city, zone, locality (precise exists in the enum) |
| Circle | a community with a board, albums, polls, events, members; never a chat |
| Circle kind label | the circle's own descriptive name for its kind |
| Women-only circle | circle that only members who answered "woman" can enter (self-declared) |
| Gender answer | the member's own one-time woman/man answer, private, used only at a women-only door |
| Assistant | circle helper who can let people in and moderate posts |
| Ask first / approval circle | organizer approves joiners, often with questions |
| Invite link | token link to join or preview a circle |
| Chapter / umbrella (Samaj) | circles grouped under one body; an umbrella update reaches every chapter |
| Drive / fundraiser | a community collection; pledges recorded, money moves outside the app |
| Pledge | a promised amount (minimum Rs 100) |
| Poll | question to the circle ("Which day?") |
| Board | circle post area: announcements, posts with photos and files, comments, reactions, pins |
| Album | named photo collection in a circle |
| Co-hosting | two circles share one event |
| Plan together | thread for organizer and going members of one event |
| Activity chat | group conversation per event in Messages, closes about 24 hours after the end |
| Moments | photos from an event, added only by people who were there |
| Regular | member keeping a spot for a repeating event |
| Meet again | private, mutual "would meet again" |
| Free right now | member signals availability |
| Familiar faces | people you keep meeting |
| Steady host | host who keeps showing up |
| Reputation labels | qualitative labels (no public ratings, no scores) |
| Trust level | ForKhatri verified, community verified, partner verified, external trusted, community submitted |
| Moderator | person with scope `milavn.moderate`; handles the report queue |
| Report action | dismiss, warn, escalate, restrict |
| Program | agenda: sessions, speakers, stalls, teams |
| Stall | expo exhibitor slot with a number |
| Team | tournament team, size limited by the organizer |
| Join link | the organizer's own online meeting link (Meet, Zoom, Teams, YouTube) |
| Follow-up | recording and notes links after an event |
| First run | the one-screen place question for a new member |
| QA members | 20 development test members (QA-USERS.md) |
| RLS | row level security, database rules deciding which rows a member can see or change |
| Definer function | database function that runs with owner rights after checking the acting member |
| Outbox | table of events written in the same transaction and handled after commit |
| FR / BR / TC / SCR / API / TBL | functional requirement, business requirement, test case, screen, endpoint, table identifiers |
| Samaj | the community body; Samaj heads run ForKhatri |
| Khatri | the community ForKhatri serves |
| DPDP | India's Digital Personal Data Protection Act 2023 |
