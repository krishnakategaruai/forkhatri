## Design System Foundations
*(Referenced per item below as "per DS Foundations"; not repeated in full per screen.)*

**Why this section exists.** `03-ux.md`'s Global UX foundations fixed the app's navigation model, terminology, and motion vocabulary so 30 flows would read as one product, not 30 fragments. This section does the same job for visual design: every token, typeface, icon style, and motion value below is fixed once, here, and every one of the 30 screens that follows references it by name rather than re-deriving it.

### 1. Color system

Grounded directly in Brand Foundation §12 ("Deep navy/midnight foundation, warm off-white surfaces, distinctive saffron/amber accent, controlled use of green for positive/trust indicators") and confirmed against 2026 UI-trend research (Envato's "Best 8 Mobile App Color Scheme Trends for 2026" and DesignRush's 2026 app-color trend report both independently name deep-navy-plus-amber as the leading palette for trust/premium-positioned products this cycle, describing 2026 as favoring "calmer, deeper... more focused on function" colors over saturated ones — directly supporting a *muted*, not neon, saffron rather than a bright dating-app orange).

**Role mapping** `surface.base`, `surface.raised`, `surface.sunken`, `text.primary`, `text.secondary`, `text.disabled`, `accent.primary`, `accent.primary-pressed`, `trust.positive` (=`color.green.600`), `trust.neutral` (=`text.secondary` — an unverified/expired layer is a *neutral*, not warning, state per BR08), `danger.action`, `border.default`, `focus.ring`.

### 2. Typography

Latin: **Inter** (variable, 400/500/600/700) — dominant modern-SaaS/interface grotesque of 2025–2026 (Linear, GitHub, Notion, Vercel). Devanagari: **Hind** — Indian Type Foundry family purpose-built for UI, proportion-matched to Inter. Telugu: **Hind Guntur** — same foundry's Telugu companion, completing the day-one English/Hindi/Telugu set (ADR-010, BR01 DEC-004).

**Type scale** `type.display` 28/34 700 (Onboarding/Splash only); `type.h1` 22/28 700 (screen headers); `type.h2` 18/24 600 (section headers); `type.body-lg` 16/24 400 (primary reading content); `type.body` 14/20 400/500 (standard UI text); `type.caption` 12/16 500 (timestamps/helper text); `type.label` 11/14 600 uppercase +0.04em (status tags). Scales with OS text-size up to 200% via `rem`.

### 3. Spacing, grid, radius, elevation

`space.1`=4 … `space.16`=64 (4px base unit). Screen margin `space.4` (base) / `space.6` (`md`+). Breakpoints: `base` 320–599px (design target), `md` ≥600px (list/detail split), `lg` ≥1024px (Admin console side rail). Radius: `radius.sm`=8 (chips/fields), `radius.md`=12 (cards/buttons), `radius.lg`=20 (sheet/takeover top corners), `radius.full` (avatars/pills). Elevation kept light per Brand's "minimal visual clutter": `elevation.1` resting cards, `elevation.2` sheets/FAB, `elevation.3` scrolled takeover header; dark theme substitutes a 1px `rgba(255,255,255,0.08)` hairline for shadow (Material 3 dark-elevation technique).

### 4. Iconography & imagery

Phosphor-Icons-style 1.5px line icons, rounded caps, filled variant only for the active tab icon (iOS SF Symbols/Material Symbols convention). Real candidate photography shown true-to-color, no beautifying filter (Brand's "human" trait). Illustration: flat, limited-palette (navy/saffron/off-white/one green accent), no mascot (rejecting the 2026 mascot-icon trend deliberately, since a recurring cartoon character reads as social-media-platform per Brand §15's rejection of that positioning). One recurring decorative motif: a subtle *jali* lattice pattern at 4–6% opacity, confined to Splash/Onboarding/emotionally-warm empty states only, never on data-dense screens. **Safety/report iconography convention (added for UI24):** each incident category (harassment, fake profile, threats, financial scam, inappropriate content) gets one fixed, consistently-used icon+neutral-ink treatment in the category picker, never a pre-emptive red/alarm color per category before the user has even selected one — color only enters once a report is actually filed and moving through triage (admin-side, UI26), per this pass's safety-report visual-pattern research on category-icon clarity.

### 5. Motion tokens

`motion.duration.instant`=0ms (reduced motion); `fast`=150ms (press/toggle/shake); `base`=220ms (tab cross-fade/sheet); `moderate`=300ms (stack push/takeover); `slow`=400ms (success sequence/onboarding slide). `ease.standard`=cubic-bezier(0.2,0,0,1) (enter); `ease.exit`=cubic-bezier(0.3,0,1,1) (exit); `ease.sheet-spring` for sheet drag-release. Skeleton shimmer: 1.2s linear sweep over `surface.sunken` (Facebook/Instagram/LinkedIn convention). Success confirmation: checkmark stroke draw (250ms) + circle scale 0.85→1.02→1.0 (300ms) + snackbar slide-up (200ms), auto-dismiss 3s.

### 6. Component & accessibility baseline

Built on accessible headless primitives (Radix UI/React Aria-class) for dialogs, sheets, toggles, comboboxes, tabs — WAI-ARIA-correct focus-trapping/live-regions by construction, inherited by every component across UI01–UI30. Minimum touch target 44×44pt/48×48dp everywhere. Contrast: `text.primary` ≥7:1, `text.secondary` ≥4.6:1, link text ≥4.5:1 (saffron-on-off-white body text uses the darker `saffron.600`, not `saffron.500`, to clear AA; large UI text on `saffron.500` fill uses `navy.900`, never white; white text on `navy.900` fill — used for sent chat bubbles, UI21 — clears 12:1). Focus ring 2px `focus.ring`, 2px offset, never suppressed. All motion collapses to `instant` under OS reduced-motion.

### 7. Theming

Light (`surface.base` = warm off-white) is the designed default per Brand §12; dark (full navy) is an equally complete alternate, following OS `prefers-color-scheme` with a manual System/Light/Dark override in Settings (WhatsApp/Instagram/LinkedIn convention). Exception: the Admin Console (UI26) defaults to dark regardless of OS setting, per 2025–2026 admin-dashboard research finding dark mode now standard for extended-session internal tools.

### Research basis (Design System Foundations)
Read in full: `ForKhatri — Brand Foundation.md` §9–§15; `03-ux.md`'s Global UX foundations; `01-business-requirements.md` BR01 DEC-004; `02-functional-requirements.md`'s architecture cross-check (React/TypeScript SPA, mobile-first). Live research: Envato/DesignRush 2026 color-trend reports (navy+amber for trust/premium); Indian Type Foundry Hind/Hind Guntur documentation; Envato "Icon design trends 2026" (mascot trend, deliberately not adopted); admin-dashboard dark-mode research (Colorlib, WrapPixel, AdminLTE 2026); UXPin/Bricx/CometChat 2026 chat-UI research (dark/navy bubbles reading as more trustworthy than lighter or green bubbles, sender differentiation via alignment+color never color-alone); Besedo/trust-and-safety-UX research (category-icon clarity, color reserved for triage state not pre-emptive alarm).
